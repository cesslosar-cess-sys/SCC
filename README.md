# Taller Pro CESS - Sistema de Mantenimiento y Control de Flota

Sistema de Gestión de Taller, Tablero Kanban de Unidades y Bitácoras Diarias para CESS.

## Despliegue en la Nube (Render.com)

1. En **Render.com**, crea un **New Web Service**.
2. Conecta este repositorio de GitHub.
3. Configuración del servicio:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
4. Haz clic en **Deploy Web Service**.
5. ¡Listo! Tu enlace permanente quedará activo 24/7 (ej: `https://taller-cess.onrender.com`).
